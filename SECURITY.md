# Security policy

PLUJ (www.pluj.us) is an event marketplace in Houston, Texas. If you think you
have found a security problem in the site, its API or this code, please tell us
privately so we can fix it before anyone else can use it.

## How to report

- **Preferred:** use GitHub's private report form: the **Security** tab of this
  repository, then **Report a vulnerability**. Only the PLUJ team can read it.
- **Or email** info@pluj.us with "Security" in the subject.

Please include what you found, the steps to see it, and what someone could do
with it. Screenshots help.

## What we ask

- Test only with your own accounts. Do not read, change or delete other
  people's data, and stop as soon as you see something that is not yours.
- Do not run denial-of-service tests, spam, or social engineering against PLUJ
  staff, hosts or vendors.
- Give us a reasonable time to fix the problem before telling anyone else.

## What we promise

- We reply within 3 business days.
- We tell you when it is fixed, and thank you by name if you would like.
- We will not take legal action against research done in good faith under
  these rules.

## Scope

In scope: www.pluj.us and pluj.us, the `/api/` routes, the Supabase project
behind them, and the code in this repository.

Out of scope: third-party services we use (Supabase, Vercel, Stripe, Resend,
Cloudflare); report those to them directly.
